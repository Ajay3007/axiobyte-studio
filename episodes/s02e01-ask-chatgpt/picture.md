# THE ONE PICTURE — s02e01

## The One Picture

A question breaks apart, travels up through the layers, and comes back one token
at a time. The machine never retrieves the answer; it builds it, piece by piece,
in front of you — each piece a pick from a spread of probabilities.

## The counter-picture

An answer that is typed out, or looked up: the reply streaming into the chat as if
someone, or something, already had it. The opening lets that picture stand for a
few seconds before the question "stops being words".

## The payoff frame

The prompt bar again, the same answer streaming word by word — and under every
word, the probability it was picked with.

## What must never happen

- A token ID shown carrying meaning; the ID is a label, the learned numbers are separate.
- An attention link pointing forward, from a position to a later one.
- The pick drawn as always the most likely candidate.
- Generation shown stopping only by an end token; the length limit appears too.
- Any visual implying the answer was retrieved, verified, or that this depicts ChatGPT's internals.
